# IP-Niretin-Catalog

Каталог для ИП Ниретин — фиды маркетплейсов (`YML-Yandex-IP.yml`,
`YMLVKIPfoto.yml`), фото сайта (`Foto-Sayt-IP-Niretin/`) и эталонная
книга каталога.

## BazaIPNiretinExel-Catalog.xlsx

Эталонная версия каталога (6850 позиций) — без упоминаний бренда
ТД РУССтанкоСбыт, подготовлена для ИП Ниретин. Собрана 08.10.2026
агентом kb-rss из двух источников:

- `CATALOG_NIRETIN_IDEAL-v5.xlsx` (07.2026) — уже де-брендированная
  версия, 5168 позиций взяты из неё текстом как есть (имя совпало с
  текущим каталогом — описание проверено, бренд отсутствует).
- `BazaRSSExel-Directus.xlsx` (текущая) — 1602 новых позиции (появились
  после 07.2026, их нет в IDEAL) и 80 позиций, где название разошлось
  между источниками (текст IDEAL не брался вслепую — помечены на ручную
  проверку, `mismatch_checked=нет`). У обеих групп бренд снят механически
  (сноска «Поставка — ТД РУССтанкоСбыт.» убрана из description,
  meta_title/meta_description перегенерированы по шаблону IDEAL).

Полный скан результата (6850/6850, 100%): упоминаний бренда в
name/description/meta_title/meta_description/manufacturer — 0.
`manufacturer` = «ИП Ниретин» у всех строк.

**Не проверено и требует отдельного решения:** колонка `image_url` —
505 строк ссылаются на `admin.td-rss.ru` (внутренний Directus РСС), не
тронуто при сборке — не моя зона решать, какие фото использовать для
Ниретина.

**Следующий шаг (по плану владельца):** книга передаётся мастер-каталогу
на чистку и проверку, затем — перенос в базу знаний ИП Ниретин
(`data/niretin/catalog.json`), которая остаётся эталоном для сайта.

94 позиции, которые есть в `CATALOG_NIRETIN_IDEAL-v5.xlsx`, но
отсутствуют в текущей `BazaRSSExel-Directus.xlsx` (не архив дублей, не
тестовый кластер UBB — причина не установлена) — в эту книгу не вошли,
переданы владельцу отдельным файлом для мастер-каталога.
